# XCOM 2's names, for the generators

Identifiers only (no game content), listed from the War of the Chosen SDK so the
generators can tell which names exist without the SDK at hand:

- `abilities.txt`: the ability template names defined in `Development/SrcOrig`
  (`CREATE_X2ABILITY_TEMPLATE`, `PurePassive`, the template-name parameters).
- `perk-icons.txt`: the textures in `UILibrary_PerkIcons` (`img:///UILibrary_PerkIcons.<name>`).
